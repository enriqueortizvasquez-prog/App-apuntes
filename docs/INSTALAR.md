# Descargar e instalar Apuntes gratis

## Descargar un solo archivo

Abre `descargas/apuntes-portable.html`. No requiere servidor, cuenta ni instalación. Guarda los datos en el almacenamiento del navegador; su disponibilidad al abrir archivos locales depende del navegador. Si está bloqueado, verás una advertencia persistente: exporta un respaldo antes de cerrar.

Los botones para compartir copias generan enlaces de la dirección desde la que abres la app. Un enlace `file://` no funciona en otro dispositivo. Para compartir con otras personas usa una dirección HTTPS común.

## Instalar desde un sitio HTTPS

- **Android, Chrome/Edge:** abre la app → menú ⋮ → Instalar app/Añadir a pantalla de inicio.
- **iPhone/iPad, Safari:** Compartir → Añadir a pantalla de inicio → Abrir como app, si aparece.
- **Windows/macOS/Linux, Chrome/Edge:** icono de instalación en la barra de direcciones o menú → Instalar.

El botón «Instalar gratis» utiliza el diálogo del navegador si está disponible y, si no, muestra estos pasos. No pide un pago ni instala un APK.

Abre la app una vez con conexión para que se descarguen los archivos. Después podrás organizar tus datos locales sin internet. Los compartidos necesitan conexión para actualizarse. La instalación desde la vista previa de Arena sirve para probar; usa un alojamiento permanente para tu uso diario.

## APK para Android

La versión 1.1.0-beta incluye un APK instalable sin depender de una página remota. Consulta `ANDROID.md` para descargar, instalar, guardar respaldos y revisar las limitaciones de su firma de prueba. El APK no es una aplicación para iPhone.

## Publicación

El propietario autorizó publicar el repositorio y GitHub confirma que ya es público. Las releases son públicas. Pages aún no está habilitado: para publicar el sitio, el propietario debe elegir Settings → Pages → Build and deployment → Source: GitHub Actions. La conexión del agente no tiene permiso para cambiar esa configuración. El APK no requiere Pages.

## Copias de seguridad

Ajustes y respaldo → Descargar respaldo JSON. Para recuperarlo: Importar respaldo. Esto reemplaza los datos locales con confirmación. Los compartidos se importan como copias independientes: los permisos y la pertenencia a grupos se obtienen exclusivamente del servidor después de iniciar sesión.

## Avisos y almacenamiento

Los recordatorios no son una alarma del sistema garantizada. Solo se revisan mientras el navegador ejecute la app. Para entregas críticas usa también una alarma de tu dispositivo. No hay integración automática con Google Calendar en esta versión.
